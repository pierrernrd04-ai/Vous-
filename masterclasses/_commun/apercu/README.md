# Aperçu de publication

Génère une page HTML unique qui montre les 20 masterclasses telles qu'elles seront publiées (page de vente, espace élève, e-mails).

```sh
python3 masterclasses/_commun/apercu/build.py apercu.html masterclasses/_commun/apercu/template.html
```

À relancer après chaque modification d'un `page-de-vente.md`, `formation.md` ou `emails.md`.
