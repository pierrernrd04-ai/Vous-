    COMMENT JOUER

    Tactile

    • Joystick gauche (n'importe où à gauche) : se déplacer. Pousse-le à fond vers le haut pour sprinter.
    • Glisser à droite : viser.
    • Gros bouton : tirer (on peut viser en le faisant glisser). Le tir automatique est activé par défaut.
    • Viseur : viser avec l'arme. Saut deux fois : propulseur. Accroupi en sprint : glissade.

    Clavier et souris

    • ZQSD ou WASD : se déplacer · Maj : sprinter
    • Clic gauche : tirer · Clic droit : viser
    • Espace : sauter (deux fois : propulseur)
    • C / Ctrl : s'accroupir, glisser en sprint
    • R recharger · 1/2/molette changer d'arme · G grenade · E Impulsion · Tab scores · Échap pause

    Manette

    • Gâchettes : viser / tirer · A sauter · B accroupi · X recharger · Y changer d'arme
    • LB grenade · RB Impulsion · L3 sprint · Start pause

    Astuces

    • 3 éliminations sans mourir : Drone de reconnaissance. 6 : Surcharge.
    • Impulsion révèle les ennemis à travers les murs. Elle se recharge avec le temps et les éliminations.
    • La santé se régénère quand tu évites les dégâts quelques secondes.
    • Les tirs à la tête infligent des dégâts supplémentaires.
