# Crédits des ressources

- `soldier.glb` : personnage « Vanguard » et animations Idle / Walk / Run, issus de Mixamo (Adobe), tels que distribués dans les exemples de three.js (`examples/models/gltf/Soldier.glb`). Les conditions de Mixamo autorisent leur utilisation dans des projets personnels ou commerciaux, jeux vidéo compris, mais pas leur redistribution en tant que ressources isolées. Le fichier a été allégé (6 jeux de coordonnées de texture inutilisés retirés) ; le maillage, les textures et les animations sont inchangés.
- Armes, décors, textures, sons et effets : générés par le code du jeu.
