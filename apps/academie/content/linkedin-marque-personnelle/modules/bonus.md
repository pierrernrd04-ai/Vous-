# Boîte à outils — LinkedIn et marque personnelle

Cette boîte à outils rassemble tout ce dont vous avez besoin pour passer à l'action : check-lists, 20 modèles de publications, 10 modèles de messages, un calendrier éditorial de 4 semaines, un glossaire et un plan d'action sur 30 jours. Remplacez toujours les crochets par des informations réelles et vérifiables.

## Check-list du profil (grille des 7 zones)

- [ ] Photo récente, nette, visage cadré, lumière de face
- [ ] Bannière personnalisée, lisible sur téléphone, texte placé à droite
- [ ] Titre en 3 blocs : métier, apport pour un public, preuve
- [ ] Section Infos en structure ACTE, avec une invitation au contact
- [ ] Section Sélection : 3 à 4 preuves à jour
- [ ] Expériences récentes rédigées avec la règle des 3 lignes
- [ ] Au moins 3 recommandations récentes et liées à votre positionnement
- [ ] URL de profil personnalisée
- [ ] Bouton principal choisi (Se connecter ou Suivre)
- [ ] Coordonnées à jour (site, prise de rendez-vous)

## Check-list avant chaque publication

- [ ] L'accroche se comprend seule
- [ ] Le texte s'adresse à mon public prioritaire
- [ ] Au moins un détail concret et vrai
- [ ] Aucune information confidentielle, aucun nom sans accord
- [ ] Paragraphes courts, lisibles sur téléphone
- [ ] Appel à l'action cohérent avec mon objectif
- [ ] Relu à voix haute
- [ ] Je suis disponible pour répondre aux commentaires

## Récapitulatif des méthodes

| Module | Méthode | En une phrase |
|---|---|---|
| 1 | Cadre VCD et méthode des 3 regards | Être Visible, Crédible, Désirable, en partant d'un diagnostic honnête |
| 2 | Méthode EPP | Expertise × Public × Preuve = positionnement clair |
| 3 | Grille des 7 zones, structure ACTE | Un profil qui convertit en 30 secondes |
| 4 | Grille des 3 E | Choisir ses formats selon Effort, Effet, Envie |
| 5 | Structure APAC, arc SCAR | Accroche, Problème, Apport, Conclusion ; Situation, Complication, Action, Résultat |
| 6 | Carte des 4 cercles, VAP, routine 15-5-5 | Un réseau aligné et des commentaires utiles |
| 7 | Escalier de confiance, méthode ÉCOUTE | Ne jamais proposer avant d'avoir créé la confiance |
| 8 | Système 4R, méthode du sandwich | Récolter, Rédiger, Recycler, Revoir ; l'IA sur votre matière |

## 20 modèles de publications

### Pilier Expertise

```
1. LA MÉTHODE
[Résultat visé] en [n] étapes. Je l'applique depuis [durée] avec [public].
Étape 1 : [...] / Étape 2 : [...] / Étape 3 : [...]
L'étape la plus souvent oubliée : [...]
```

```
2. LES ERREURS FRÉQUENTES
J'ai [vu / relu] [nombre réel] [situations] cette année. Les 3 erreurs qui reviennent :
- [Erreur] → [solution]
- [Erreur] → [solution]
- [Erreur] → [solution]
```

```
3. LA QUESTION DU CLIENT
Question reçue cette semaine : « [question anonymisée] »
Ma réponse en 3 points : [...]
La réponse courte : [une phrase].
```

```
4. LA CHECK-LIST
Avant de [action importante], vérifiez ces [n] points :
[ ] [...] [ ] [...] [ ] [...]
Gardez cette liste pour votre prochain [événement].
```

```
5. LE MYTHE ET LA RÉALITÉ
Mythe : « [idée reçue de votre secteur] »
Réalité : [ce que montre votre expérience].
Ce que je conseille à la place : [...]
```

```
6. LE LEXIQUE
Trois mots que [public] entend souvent sans qu'on les lui explique :
[Mot 1] : [définition simple]. [Mot 2] : [...]. [Mot 3] : [...].
```

```
7. LE COMPARATIF
[Option A] ou [option B] ? Ça dépend de 3 critères :
1. [Critère] 2. [Critère] 3. [Critère]
Mon choix dans [situation type] : [...]
```

### Pilier Terrain

```
8. LA LEÇON APPRISE
[Erreur ou difficulté vécue, en une phrase.]
Ce que j'en ai retenu : 1. [...] 2. [...] 3. [...]
Si c'était à refaire : [...]
```

```
9. L'AVANT / APRÈS
Avant : [situation chiffrée]. Après : [situation].
Le vrai levier n'était pas [idée reçue] mais [levier].
```

```
10. LES COULISSES
Ce qu'on ne voit pas de mon métier : [tâche peu connue].
[3 à 5 lignes concrètes.] Pourquoi ça compte pour vous : [...]
```

```
11. L'HISTOIRE SCAR
Situation : [...]. Complication : [...]. Action : [...].
Résultat : [...]. Ce que vous pouvez en retenir : [...]
```

```
12. LE PREMIER JOUR
Je me souviens de mon premier [poste / client / chantier].
Ce que j'ignorais alors : [...]. Ce que je dirais au débutant que j'étais : [...]
```

```
13. LA MISE À L'HONNEUR
Merci à [Prénom Nom, avec son accord] pour [action précise].
Ce que cela a changé : [...]. Ce que j'en retiens : [...]
```

```
14. LE PARCOURS
Il y a [n] ans, je [situation]. Aujourd'hui, je [situation].
Les 3 décisions qui ont tout changé : [...]
```

### Pilier Point de vue

```
15. L'OPINION ARGUMENTÉE
Je ne suis pas d'accord avec [idée répandue].
Pourquoi : 1. [...] 2. [...] 3. [nuance].
Ma position : [...]
```

```
16. LA PRÉDICTION PRUDENTE
Ce que je vois changer dans [secteur] : [tendance observée].
Mes indices : [faits vérifiables]. Ce que je ne sais pas encore : [...]
```

```
17. LA RESSOURCE COMMENTÉE
J'ai lu [titre / source officielle]. L'idée clé : [...].
Ce que j'en retiens pour [public] : [...]. Ma réserve : [...]
```

```
18. LE BILAN
[Période] en [n] chiffres réels : [...]
Ce que je change pour [période suivante] : [...]
```

### Publications d'opportunité

```
19. LA PORTE OUVERTE
Une fois par mois, je rappelle ce que je fais : j'aide [public] à [résultat].
Si [situation déclencheur] vous concerne, écrivez-moi.
Je vous dirai honnêtement si je peux vous aider ou vers qui vous orienter.
```

```
20. LA RECHERCHE CIBLÉE
Je recherche un poste de [intitulé] en [région], dans [type d'entreprise].
Ce que j'apporte : [compétence prouvée 1], [2], [3].
Une mise en relation avec [type de personne] m'aiderait beaucoup. Merci !
```

## 10 modèles de messages

```
1. INVITATION APRÈS LECTURE
Bonjour [Prénom], votre publication sur [sujet] m'a fait réfléchir,
notamment [détail]. Je travaille aussi avec [public commun]. Ravi(e) d'échanger ici.
```

```
2. INVITATION APRÈS ÉVÉNEMENT
Bonjour [Prénom], nous étions tous deux à [événement] [jour].
Votre remarque sur [sujet] m'a marqué(e). Au plaisir de suivre vos publications.
```

```
3. REMERCIEMENT APRÈS ACCEPTATION
Merci d'avoir accepté, [Prénom]. Je suis avec intérêt vos publications sur [sujet].
Belle fin de semaine.
```

```
4. APPORT DE VALEUR
Bonjour [Prénom], suite à votre commentaire sur [sujet], voici [ressource]
que j'utilise pour [usage]. En espérant qu'elle vous serve.
```

```
5. PROPOSITION D'ÉCHANGE
[Prénom], nos échanges sur [sujet] m'ont donné envie d'aller plus loin.
Seriez-vous ouvert(e) à 20 minutes d'échange dans les prochaines semaines ?
Je m'adapte à vos disponibilités.
```

```
6. RELANCE UNIQUE
Bonjour [Prénom], je me permets de revenir vers vous, au cas où mon message
serait passé inaperçu. Aucune urgence, et merci d'avance.
```

```
7. DEMANDE DE RECOMMANDATION
Bonjour [Prénom], j'ai beaucoup apprécié notre travail sur [projet].
Accepterais-tu d'écrire quelques lignes de recommandation, par exemple sur
[compétence précise] ? Je serai ravi(e) de te rendre la pareille.
```

```
8. MESSAGE AU RÉSEAU (RECHERCHE D'EMPLOI)
Bonjour [Prénom], je recherche un poste de [intitulé] en [région], idéalement
dans [type d'entreprise]. Si tu entends parler d'une opportunité ou connais
quelqu'un à qui poser quelques questions, je t'en serais reconnaissant(e).
```

```
9. MESSAGE APRÈS CANDIDATURE
Bonjour [Prénom], je viens de postuler au poste de [intitulé].
Mon expérience en [compétence clé] correspond à [besoin de l'offre].
Je reste à votre disposition pour en parler.
```

```
10. ORIENTATION VERS UN CONFRÈRE
Merci pour votre confiance, [Prénom]. Honnêtement, votre besoin relève
davantage de [spécialité]. Je vous recommande [Prénom Nom], qui [compétence].
Voulez-vous que je vous mette en relation ?
```

| 2 | Mardi | Point de vue | 15. Opinion argumentée | Texte | Différenciation |
| 2 | Vendredi | — | Revue rapide des commentaires reçus | — | Récolter des idées |
| 3 | Mardi | Expertise | 2. Erreurs fréquentes | Document PDF | Enregistrements |

## Glossaire

| Terme | Définition |
|---|---|
| Abonné | Personne qui suit vos publications sans être forcément connectée à vous |
| Accroche | Première ou deux premières lignes d'une publication |
| Algorithme | Systèmes automatiques qui choisissent et ordonnent les publications du fil |
| Appel à l'action | Phrase finale qui invite le lecteur à agir |
| Bannière | Image horizontale en haut du profil |
| Calendrier éditorial | Planning des publications à venir |
| Document (carrousel) | Publication d'un PDF que l'on fait défiler page par page |
| Fil d'actualité | Page où défilent les publications |
| IA générative | Outil capable de produire du texte ou des images à partir d'une consigne |
| Impressions | Nombre d'affichages d'une publication |
| InMail | Message à une personne hors de vos relations, réservé aux offres payantes |
| Marque personnelle | Ensemble des impressions que l'on retient de vous professionnellement |
| Newsletter LinkedIn | Série d'articles à laquelle les membres peuvent s'abonner |
| Open to Work | Fonction signalant que vous êtes à l'écoute d'opportunités |
| Pilier de contenu | Grand thème récurrent de vos publications |
| Pod d'engagement | Groupe organisé pour réagir mutuellement aux publications, contraire aux règles |
| Positionnement | Place que vous voulez occuper dans l'esprit de votre public |
| Prescripteur | Personne qui peut vous recommander à votre public |
| Recommandation | Texte rédigé par un contact pour attester de votre travail |
| Relation | Contact de 1er niveau, connecté après acceptation d'une invitation |
| RGPD | Règlement européen encadrant l'usage des données personnelles |
| Section Sélection | Zone du profil où épingler publications, liens et documents |
| Signal d'intention | Indice qu'une personne pourrait avoir besoin de vous maintenant |
| Vente sociale | Usage des réseaux sociaux pour nouer des relations commerciales |

## Plan d'action sur 30 jours

### Semaine 1 : diagnostic et positionnement

- [ ] Faire la méthode des 3 regards et noter le score de départ sur 20
- [ ] Fixer un objectif principal mesuré en conversations
- [ ] Rédiger la phrase EPP et les 3 piliers
- [ ] Bloquer deux créneaux hebdomadaires dans l'agenda

### Semaine 2 : profil

- [ ] Nouvelle photo et bannière
- [ ] Titre en 3 blocs, section Infos en structure ACTE
- [ ] Règle des 3 lignes sur les deux derniers postes
- [ ] Trois demandes de recommandation personnalisées
- [ ] Viser au moins 50 sur 70 à la grille des 7 zones

### Semaine 3 : réseau et premières publications

- [ ] Dresser la carte des 4 cercles
- [ ] Lancer la routine 15-5-5 trois jours par semaine
- [ ] Publier deux fois avec la structure APAC
- [ ] Créer la banque d'idées (au moins 10 idées)

### Semaine 4 : système et opportunités

- [ ] Séance de rédaction groupée de 90 minutes
- [ ] Publier la « porte ouverte » (modèle 19) ou la « recherche ciblée » (modèle 20)
- [ ] Envoyer trois messages selon la règle du 1-2-3
- [ ] Remplir le premier tableau de bord et refaire le score sur 20
