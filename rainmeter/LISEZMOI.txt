MES WIDGETS DANS RAINMETER - mode d'emploi (sans PowerShell)
============================================================

Tous les widgets sur le bureau Windows : les 14 du tracker et les 3 de Dan't.

1. Installez Rainmeter (gratuit) : https://www.rainmeter.net
   (installeur direct : https://github.com/rainmeter/rainmeter/releases/download/v4.5.28.3936/Rainmeter-4.5.28.exe)
2. Téléchargez MesWidgets.rmskin :
   https://pierrernrd04-ai.github.io/Vous-/rainmeter/MesWidgets.rmskin
   puis double-cliquez dessus > Install. Le plugin WebView2 est inclus.
3. Dans le bloc qui apparaît, collez le lien de vos widgets du tracker
   (celui de Lively) et choisissez le thème. Le bloc Dan't s'ouvre à droite ;
   s'il demande un code : iPhone > Dan't > roue dentée > Widgets sur le PC.
4. Dans Lively, mettez un fond simple ou quittez Lively.

Ctrl + glisser : déplacer. Ctrl + clic droit : menu (changer le lien, actualiser).

Le script Installer.ps1 fait la même chose en ligne de commande, pour les PC
où PowerShell est autorisé. build.py refabrique MesWidgets.rmskin depuis src/.
